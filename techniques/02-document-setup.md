# 2. Belge kurulumu

- **File > New**: 1920 x 1080 px, 72 ppi, RGB 8 bit, arka plan beyaz, Color Profile: *Don't Color Manage*, Pixel Aspect: *Square*.
- Tüm render'ları sürükle-bırak. Smart Object olarak gelir. Hizala ve Enter'a bas.
- Başlangıç katman sırası (alttan üste): Background → arazi (shader'sız) → arazi NMS (geçici) → kalabalık → oyuncular → oyuncu NMS.
- Render'lar 1920x1009 gibi biraz farklı boyutta gelirse transform ile tuvale uydur.
