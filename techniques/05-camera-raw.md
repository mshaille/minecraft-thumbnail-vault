# 5. Camera Raw Filter

Her oyuncu katmanına ve kalabalığa uygulanır: **Filter > Camera Raw Filter (Shift+Ctrl+A)**. Katman Smart Object olduğu için Smart Filter olarak eklenir ve sonradan düzenlenebilir. Videodaki kişi ayarları kendi kayıtlı preset'inden uyguluyor.

## Ana preset (videoda ayrıca gösterilen)
| Panel | Ayar |
|---|---|
| Light | Exposure **+0.10** · Contrast **+13** · Highlights **+15** · Shadows **+7** · Whites **−21** · Blacks **+62** |
| Color | WB As Shot · Temp 0 · Tint 0 · Vibrance 0 · Saturation **+18** |
| Effects | Texture **+9** · Clarity **+11** · Dehaze 0 · Vignette 0 · Grain 0 |
| Color Mixer (HSL, tüm Hue 0) | Red S **+13** L **+16** · Orange S **+39** L **−3** · Yellow/Green 0 · **Aqua S +86 L +49** · **Blue S +100 L +52** · Purple/Magenta 0 |
| Detail | Sharpening **11** · Noise Reduction **16** · Color Noise Reduction **17** |
| Curve, Color Grading, Optics, Lens Blur, Calibration | Dokunulmamış |

## Zırh preset'i
Zırhlı oyuncu için ayrı preset: **Texture +50, Clarity +11**. Zırh dokusunu öne çıkarır.

> [!note] Mavi tonlu bir sahne olduğu için Aqua/Blue doygunluğu yüksek tutulmuş. Başka renk temasında HSL'deki doygunluk artışını sahnenin ana renklerine kaydır.
